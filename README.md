Task 29-Random Forest Classifier


This project focuses on building a Random Forest Classification model and comparing its performance with a Decision Tree Classifier.

The project demonstrates how ensemble learning combines multiple decision trees to improve model performance and generalization.

Objective

Understand Random Forest classification.

Build a Decision Tree baseline model.

Build and evaluate a Random Forest model.

Compare the performance of both models.

Analyze feature importance.

Experiment with different numbers of trees using n_estimators.


 Dataset

Breast Cancer Wisconsin Dataset

The dataset is available through Scikit-learn and contains features related to breast cancer diagnosis.

🛠️ Tools & Technologies

Python

Pandas

NumPy

Matplotlib

Scikit-learn

Jupyter Notebook


 Steps Performed

1. Imported the required libraries.


2. Loaded the Breast Cancer Wisconsin dataset.


3. Explored the dataset and checked for missing values.


4. Split the data into training and testing sets.


5. Built a Decision Tree Classifier.


6. Built a Random Forest Classifier.


7. Generated predictions.


8. Compared model accuracy.


9. Evaluated the Random Forest using a confusion matrix and classification report.


10. Analyzed feature importance.


11. Experimented with different n_estimators values.


12. Compared the final model performance.



Evaluation Metrics

Accuracy

Precision

Recall

F1-Score

Confusion Matrix


 Key Learning

This project helped me understand how Random Forest uses multiple decision trees to create a stronger and more stable classification model. I also learned how to evaluate classification models and identify important features.

 Conclusion

The Random Forest Classifier provides a practical example of ensemble learning and can improve generalization compared with a single decision tree.
